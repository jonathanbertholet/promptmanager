版本 3.0.3

  • 侧边栏插入更加可靠；右键点击已保存提示词可直接插入当前页面。
版本 3.0.2
  • 标签统一以小写且唯一的形式保存，不再因大小写不同而拆成多个筛选项。
  • 从未修改过标签设置时，备份导出也会正确保留标签；导入支持已解析的 v2 对象。
  • 页面内界面会在观察器挂载前完成加载；切换视图时会清理滚动条计时器。
版本 3.0.1
  • 社区网站上的提示词导入不再依赖静态内容脚本，因此已有安装不会在更新后被 Chrome 禁用。
版本 3.0
  • 可从侧边栏分享到 Open Prompt Database，包括你从社区导入后修改的副本。
  • 在已启用的网站上点击侧边栏提示词即可插入聊天输入框；带变量的提示词会在侧边栏填写变量，未启用的网站可手动选择输入框。
  • 侧边栏打开时隐藏页面内启动器，并记住每个网站上最近一次成功使用的聊天输入框。
  • 新增首次使用引导：选择启动方式，再点击 AI 助手授予访问权限、打开网站并打开侧边栏。
  • 修复 ChatGPT 和 Perplexity 中提示词重复插入的问题。
  • 改进分享及用户名检查错误提示；Chrome 商店版和解压安装版都可从社区网站导入提示词。
版本 2.9.1

  • Open Prompt Database 设置中新增发布用户名及发布开关。
版本 2.9

  • 增加重复检测：若提示词已在本地库中，网站会显示“已在库中”，不会再次添加副本。
  • 设置中加入社区提示词库入口；Chrome 商店扩展可从社区网站一键导入，更新时无需新增社区网站权限。
