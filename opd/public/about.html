Browse & search

  • Home — popular and recent prompts, with quick tag filters.
  • Browse — full catalog with sort by recency, imports, or A→Z.
  • Tags — popular tags in the menu or the full A–Z directory.
  • Search — press ⌘K (or CtrlK) or use the header search icon.

Import into Open Prompt Manager

Use Add to Open Prompt Manager on any prompt card or detail page. Prompts are saved locally in the extension with a stable opd: id — re-importing updates the same entry when the catalog changes, and duplicates show Already in library.

Requires Open Prompt Manager 2.9+ from the Chrome Web Store (or a current dev build).

Trust & safety

  • Entries are community-submitted and unverified.
  • Never publish API keys, passwords, or private data in prompts.
  • Review prompt text before pasting into any AI assistant.
  • Use Report on a prompt page if you see abuse or spam.
